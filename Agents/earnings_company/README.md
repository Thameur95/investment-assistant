Earnings & Company Agent
Agent d'analyse des résultats financiers et des informations propres à l'entreprise.

Mode : Shadow / Observation uniquement.

Objectifs :

analyser les résultats publiés ;
comparer réel / consensus / période précédente ;
analyser la guidance ;
identifier les KPI importants de l'entreprise ;
détecter accélération et décélération des KPI ;
produire une conclusion pouvant être POSITIVE, NEGATIVE, NEUTRAL ou MIXED.
Sécurité :

ObservationOnly = True
V1ExecutionChanged = False
PortfolioV1Changed = False
Cet agent ne peut ni modifier les décisions V1, ni ouvrir ou fermer une position V1.
